Projects Overview

In these classification projects, I focused on predicting categorical outcomes using various machine learning algorithms. Each dataset underwent preprocessing for feature selection. I utilized confusion matrices and classification reports to validate performance, measuring metrics like accuracy, precision, recall, and F1-score. These projects emphasize the significance of data quality and model tuning for reliable predictions.

	1.	Covid Image Classification: A project to classify images related to COVID-19 using convolutional neural networks (CNNs).
	2.	Face Image Classification: Utilizing deep learning techniques to classify images based on facial attributes.
	3.	Forest Type Classification: Implementing classification algorithms to categorize different types of forests based on image data.
	4.	Handwritten Digits Classification: Using neural networks to recognize and classify handwritten digits from the MNIST dataset.
	5.	ML-Based Disease Prediction Model: Developing a predictive model for disease classification based on patient data.
	6.	Salary Prediction: Using classification techniques to predict salary ranges based on various features.
	7.	Wine Quality Prediction: Classifying wine quality based on physicochemical properties using machine learning algorithms.
